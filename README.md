# Madison Metro Bus Analysis
### by Alton Hipps

This repository holds code I created to read the Madison Metro API, collate data into csvs, analyze the data for patterns in bus fullness, and display the data as an interactive timeseries/heatmap via keplerGL.

## How to use this code yourself
The necessary scripts are located within the Buses directory. The ReadMe file within that folder explains each of the files and what they are used for. The other files in this repo are used for the pages deployment.
